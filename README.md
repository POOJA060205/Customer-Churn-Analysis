 Customer Churn Analysis Dashboard

## Project Overview
This project focuses on analyzing customer churn behavior using SQL and Power BI. The dashboard provides insights into customer retention patterns, churn trends, contract-based churn, payment method analysis, and tenure-based customer behavior through interactive visualizations and KPI metrics.

The main objective of this project is to identify factors contributing to customer churn and help businesses improve customer retention strategies through data-driven insights.


## Tools & Technologies Used
- SQL (SQLite)
- Power BI
- DAX
- Data Visualization
- Data Analysis



## Dataset Information
The dataset contains customer-related information such as:
- Customer ID
- Gender
- Age
- Tenure
- Monthly Charges
- Contract Type
- Payment Method
- Churn Status



## Key KPIs
- Total Customers
- Churned Customers
- Churn Rate
- Average Monthly Charges



## Dashboard Features
- Customer Churn Distribution Analysis
- Contract Type Churn Analysis
- Payment Method Analysis
- Customer Tenure Churn Analysis
- Interactive Filters (Gender, Contract Type, Payment Method)
- Business Insights Section



## Business Insights
- Month-to-month contracts show the highest churn.
- Customers with lower tenure are more likely to churn.
- Overall churn rate is approximately 36%.
- Long-term contracts improve customer retention.



## SQL Analysis Performed
- Total customer analysis
- Churn rate calculation
- Retention rate analysis
- Contract-based churn analysis
- Payment method analysis
- Tenure segmentation
- Age group analysis
